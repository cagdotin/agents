# References

Focused shared references for day-to-day development in this repository.

## What belongs here

Top-level `docs/references/` is only for **shared repo-wide references** with no narrow owner.

Keep a reference here when it applies across multiple skills, modules, or workflows and would feel orphaned next to any single owner.

## What does not belong here

- skill-local procedural notes
- extension-local implementation notes
- module-owned pattern docs
- temporary investigation writeups

If a reference has a natural owner, move it next to that owner.

## Files

- `pi-api-reference.md` — project-focused quick reference for Pi extension and skill APIs, patterns, and gotchas.
