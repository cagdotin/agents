# Engineering

Skills for code, architecture, and software-design work.

This category is for engineering methodologies and judgment frameworks rather than external-system integrations.

- **[setup-repo-methodology](./setup-repo-methodology/SKILL.md)** — Bootstrap repo-local issue-tracker, triage-label, and context/ADR consumption docs for the shared engineering workflow.
- **[setup-matt-pocock-skills](./setup-matt-pocock-skills/SKILL.md)** — Upstream-compatible bootstrap skill for AGENTS/CLAUDE issue-tracker, triage-label, and domain-doc configuration.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Stress-test a plan against the repo's domain glossary and ADRs, updating `CONTEXT.md` and ADRs inline when needed.
- **[zoom-out](./zoom-out/SKILL.md)** — Ask for a higher-level map of an unfamiliar area using project vocabulary.
- **[plan](./plan/SKILL.md)** — Create implementation specs and execution plans for medium and large work.
- **[to-prd](./to-prd/SKILL.md)** — Turn current context into a PRD and publish it to the configured issue tracker.
- **[to-issues](./to-issues/SKILL.md)** — Break a plan, spec, or PRD into tracer-bullet implementation issues.
- **[review](./review/SKILL.md)** — Reusable, lens-based code review methodology for correctness, architecture, security, testing, and dependency risk.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — Find deepening opportunities in a codebase, using the project's domain language and architectural decisions to propose better seams, more locality, and more leverage.
